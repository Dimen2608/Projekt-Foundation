# Entscheidungen

> **Ein Filter, kein Archiv.** Das Kernproblem, gegen das diese Datei antritt: Jede
> Prüfrunde findet dieselben Themen und macht daraus neue Aufgaben. Ein Eintrag hier lässt
> den nächsten Fund **abprallen**, statt ihn erneut zu behandeln.

## Regeln für diese Datei

1. **Jede Grundsatzentscheidung kommt hierher** — besonders die, einen Zustand bewusst
   hinzunehmen statt ihn zu beheben. Nicht in den Aufgabenbestand, nicht in eine Projektnotiz.
2. **Jeder Eintrag braucht Filtersatz und Bedingung zum Neuaufmachen.** Ohne beides ist es
   keine Entscheidung, sondern eine Verdrängung.
3. **Wiederholt ein neuer Punkt einen bestehenden Eintrag**, wird die Nummer genannt, statt
   eine neue Aufgabe aufzumachen.
4. **Eine Entscheidung wirkt erst, wenn sie im Arbeitssystem angekommen ist.** Bis dahin
   gehört „im System durchziehen" in den Aufgabenbestand.
5. **Nachträge werden angehängt, nie eingeschoben.** Eine eingeschobene Änderung verschiebt
   jede Zeilenangabe, die auf diese Datei zeigt, und bricht die Verweise still.
6. **Nummern werden nie neu vergeben.** Eine zurückgezogene Entscheidung bleibt stehen und
   wird als zurückgezogen gekennzeichnet.

## Eintragsmuster

### E-`<NNN>` — `<Die Entscheidung als vollständiger Satz, nicht als Thema>`

**Entschieden von `<wer>` am `<Datum>`.** `<Wörtliche Ansage, wenn es eine gab.>`

**Anlass:** `<Der Fund oder die Frage, die dazu geführt hat — gemessen, mit Belegstelle und
Messstand. Ein Anlass ohne Messung ist eine Erinnerung.>`

**Grundsatz:** `<Was ab jetzt gilt. Prüfbar formuliert: Ein Dritter muss entscheiden
können, ob ein künftiger Fall darunter fällt.>`

**Wirkung im Ablauf:** `<Welchen Pflichtschritt diese Entscheidung ersetzt. Eine
Entscheidung, die nur hinzukommt, ist begründungspflichtig — sonst wächst das Vorgehen, bis
niemand mehr alles ausführt.>`

**Was sie nicht aufhebt:** `<Die Grenze. Was weiterhin gilt, damit die Entscheidung nicht
mehr trägt, als sie soll.>`

**Filtersatz:** `<Der Satz, der künftig gesagt wird — und die Antwort. Form: „«Typischer
Einwand»" — «Antwort in einem Halbsatz».>`

**Bedingung zum Neuaufmachen:** `<Das Ereignis, bei dem diese Entscheidung neu verhandelt
wird — messbar, oder ausdrücklich „keine absehbare". Eine Bedingung, die niemand prüfen
kann, ist keine.>`
