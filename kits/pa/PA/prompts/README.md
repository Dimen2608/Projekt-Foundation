# Prompts

Fertige Prompts für Projekte ohne eigene Arbeits-Session. {{NAME}} startet sie selbst dort; der PA
gibt sie zusätzlich als Textblock im Chat aus. Ein Prompt ist für sich allein verständlich: Rolle,
Ziel, Quellen, Grenzen, Abnahme, Meldeweg, Modell und Effort.

Dateiname: `NN-kurzer-titel.md`.
